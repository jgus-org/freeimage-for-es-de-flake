Evaluating and building this flake carries no upstream bytes beyond the nixpkgs backends above, and nothing is fetched from the FreeImage project at any phase. One runtime detail bears on upstream's acknowledgement clause: `FreeImage_GetCopyrightMessage()` answers with this library's own attribution string, because the classic signature has to be answered and there is no upstream library beside it to acknowledge — so an application that builds its "About" box from that call reads our name, not FreeImage's.
